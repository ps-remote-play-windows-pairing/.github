## Getting Started Playbook

On PS5, open Settings → System → Remote Play and turn on Enable Remote Play for your user. To wake the console remotely, go to System → Power Saving → Features Available in Rest Mode. Enable Stay Connected to the Internet and Enable Turning On PS5 from Network.

Install Sony's Windows client and connect the DualSense with a USB data cable. Sign in with the same PlayStation account you use on PS5 and select PS5 while the console is awake. If it is not found, open Pair Device in the console's Remote Play settings and enter its code when prompted by the client.

## Everyday Use

Launch the app with the controller plugged in and select the last console you used. If the login prompt returns, check that you are signing in to the right console profile. Features such as microphone mute are available from the session controls, so check the mute state before joining a party. When you disconnect, choose whether to leave the console running or put it back into rest mode.

## Troubleshooting Common Issues

Install issues? Use the Windows installer and confirm the PC meets the listed OS requirements.  
Performance problems? Pause large transfers and try wired Ethernet to isolate Wi-Fi jitter.  
Edition differences? The client needs no unlock key; check the PlayStation account if sign-in fails.
Compatibility? Confirm the controller and cable work over USB, and check Sony's restrictions if a specific title or screen cannot be streamed.  
Update failures? Update the console and client through their official routes, restart both, then retry on the same network before re-pairing.
